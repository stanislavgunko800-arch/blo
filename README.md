# SayYes — пробный журнал колориста

## Запуск

Node.js 24.5+; `npm start` из каталога репозитория. Зависимости устанавливать не нужно. Сервер слушает только локальный интерфейс, по умолчанию порт 3000; изменить порт: `PORT=3001 npm start`.

## Разделы приложения

- **Главная** — быстрый поиск клиента, создание карточки и переход к напоминаниям.
- **Клиенты** — поиск, сортировка, контакты и история окрашиваний. Карточка открывается после выбора клиента.
- **Напоминания** — клиенты, которым пора предложить следующий визит.
- **Настройки** — экспорт и восстановление журнала, справка о голосовом помощнике и контакты разработчицы.

Соцсети, напоминания и рейтинг раскрываются в форме клиента по необходимости. В форме окрашивания голосовой ввод находится в блоке «Заполнить голосом».

## Возможности

Карточки клиентов, поиск по имени, номеру телефона и соцсетям, история окрашиваний с редактированием, повторение рецепта, фото до/после с предпросмотром, видео MP4/WebM/MOV до 20 МБ, экспорт и восстановление JSON с вложениями. Поддержка MOV зависит от кодеков браузера — для совместимости используйте MP4 H.264.

При первом открытии добавляются три вымышленные демонстрационные карточки. Формулы в них иллюстративные.

## Голосовой помощник

В форме нового окрашивания можно записать до 3 минут с микрофона или загрузить аудио до 20 МБ. Микрофону нужен localhost или HTTPS и разрешение браузера. Доступны прослушивание и скачивание записи. После закрытия формы несохранённая аудиозапись удаляется из памяти; аудио не включается в историю и экспорт.

Кнопка «Расшифровать запись» отправляет аудио в OpenAI, получает текст и предлагает значения для полей. Текст можно исправить и повторно разобрать кнопкой «Разнести текст по графам». Мастер проверяет предложенные значения, отмечает нужные поля и применяет их. ИИ не сохраняет окрашивание автоматически. Проверьте номера красителей, граммы и проценты: распознавание может ошибаться.

Для настоящего ИИ задайте ключ OpenAI в переменной окружения сервера `AI_API_KEY` и перезапустите `npm start`. Ключ не вводится в интерфейсе и не передаётся браузеру. В облачной среде используйте защищённые настройки секретов с назначением `api.openai.com`, затем сохраните настройки и опубликуйте среду. API требует отдельного баланса/доступа; подписка ChatGPT не заменяет его.

По умолчанию используются `whisper-1` для аудио и `gpt-4o-mini` со строгой JSON-схемой для распределения по полям. Допустимы серверные переменные `AI_AUDIO_MODEL`, `AI_TEXT_MODEL`; `AI_BASE_URL` — базовый URL совместимого API с путём `/v1/`. Не добавляйте ключи в репозиторий или архив. Node использует штатные переменные HTTPS_PROXY/HTTP_PROXY и CA trust через `--use-env-proxy`.

Без ключа фото, видео, ручное заполнение и запись микрофона работают; расшифровка и разбор явно сообщают об отсутствии подключения. Реальный вызов OpenAI при разработке не проверен: ключ в среде отсутствует.

В истории нажмите «Редактировать»: можно изменить дату, формулу и заметки, заменить фото/видео или отметить удаление сохранённых вложений. Изменения сохраняются в исходной записи. Закрытие формы отменяет правки. Повторение формулы по-прежнему создаёт новую запись без старых фото и видео.

## Хранение

Текст и уменьшенные фото сохраняются в localStorage, видео — в IndexedDB текущего браузера и адреса. Сервер не хранит журнал. Резервная копия JSON включает фото и видео (импорт до 100 МБ). Старые резервные копии без видео поддерживаются. Восстановление заменяет весь журнал; сначала сделайте экспорт.

Это локальный прототип без аккаунтов и синхронизации. При смене браузера/адреса или очистке хранилища данные недоступны. Храните резервные копии безопасно: они содержат персональные данные. Для публичного запуска необходимы авторизация, ограничения пользователей/расходов ИИ, HTTPS, серверное хранение и резервирование; не выставляйте этот локальный сервер в интернет без этих изменений.

## Проверки

`npm run check` — синтаксис. `npm test` — серверная интеграция с локальным тестовым ИИ (аудиозапрос, JSON-схема, проверка полей, ошибки провайдера, отсутствие ключа, запрет чужого Origin). Тест не вызывает OpenAI и не оценивает качество реального распознавания.

`npm run test:browser` — функциональные проверки в запущенном Chromium на порту отладки 9222 и приложении на порту 3000. Нужен отдельный тестовый профиль Chromium и параметры `--use-fake-ui-for-media-stream --use-fake-device-for-media-stream`. Проверка меняет тестовые данные текущего профиля; используйте только отдельный профиль. Проверяются запись микрофона с тестового устройства, отсутствие ключа, заполнение полей с тестовыми ответами ИИ, видео, перезагрузка и экспорт/импорт с вложениями, мобильная форма.

`npm run test:edit` — браузерная проверка редактирования с временными тестовыми записями: сохранение идентификатора и вложений, перезагрузка, отмена, ошибка хранилища, удаление/замена медиа и повтор рецепта. Требует приложение на порту 3000 и тестовый Chromium на 9222. Используйте отдельный тестовый профиль.

В карточке клиента есть личный рейтинг 1–5 звёзд с цветовой индикацией и сбросом. Кнопка «Редактировать клиента» меняет имя, телефон, Instagram, Telegram, другие контакты и заметки, сохраняя историю окрашиваний. Соцсети можно указывать как ник или ссылку. Рейтинг и контакты включаются в резервные копии; старые записи без этих полей совместимы.

`npm run test:clients` — проверки редактирования данных клиента, рейтинга, поиска по соцсетям и экспорта/импорта. Требует отдельный тестовый Chromium на порту 9222 и приложение на 3000.

Клиенты отображаются по фамилии (русский алфавит), затем по имени. В карточке есть отдельное поле «Фамилия». Для старых данных без него используется последнее слово полного имени; для сложных имён или записи «Фамилия Имя» уточните фамилию вручную. Сортировка не меняет историю или сохранённый порядок данных. На главной — логотип SayYes, внизу боковой панели — ссылка на Instagram салона.

`npm run test:home` — проверка сортировки, фамилий, поиска, главной страницы и мобильной вёрстки (тестовый Chromium:9222, приложение:3000).

## Поиск, почта и возвращение клиентов

В списке можно выбрать поле поиска: все данные, фамилия, имя, телефон, ник/соцсети или почта. Отдельно выбирается порядок: фамилия, имя, давность визита или ближайшая дата контакта. Почта добавляется через «Редактировать клиента» и сохраняется в резервной копии.

Раздел «Пора связаться» и одноимённый фильтр показывают клиентов, которым пора предложить следующее окрашивание. В карточке задаются интервал (по умолчанию 42 дня), конкретная дата контакта, включение напоминаний, канал связи и согласие клиента. Кнопка «Отложить на 7 дней» переносит контакт. Новое окрашивание обновляет расчёт, если перекрывает предыдущую дату напоминания.

«Подготовить сообщение» создаёт редактируемый текст: его можно скопировать, открыть письмо в почтовой программе или профиль клиента. Сообщения автоматически не отправляются, фоновых уведомлений при закрытом приложении нет. Модуль `reminders.js` содержит общие правила и контракт для будущих интеграций; подробности в [docs/integrations.md](docs/integrations.md).

Внизу страницы — ссылка на Instagram разработчицы Ирины Гвоздевой и контактный телефон.

`npm test` выполняет тесты локального ИИ API и расчёта напоминаний без внешних запросов. `npm run test:followups` проверяет новые фильтры, почту и напоминания в тестовом Chromium на 9222. Для другого порта приложения задайте `APP_URL`, например `APP_URL=http://localhost:3010 npm run test:followups`. Остальные браузерные проверки также поддерживают APP_URL.

`npm run test:navigation` — проверка четырёх разделов, быстрых действий, сохранения окрашивания, перезагрузки, кнопки «Назад» и мобильного меню. По умолчанию приложение:3012 и отдельный тестовый Chromium:9223. `APP_URL` и `CDP_URL` позволяют изменить адреса; остальные браузерные проверки также поддерживают `CDP_URL` (по умолчанию http://localhost:9222).
