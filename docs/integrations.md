# Основа интеграции напоминаний

Текущая версия ничего не отправляет автоматически. `reminders.js` считает дату контакта и создаёт независимый от провайдера черновик через `SayYesReminders.integrationDraft(client, channel, asOf)`. Модуль работает в браузере и Node.js без зависимостей.

В карточке сохраняются `email`, `followUpDays` (1–365, по умолчанию 42), `followUpDate` (ручная дата), `remindersEnabled`, `reminderChannel` и `reminderConsent`. Все поля необязательны для старых резервных копий. Без визитов напоминание возникает только при явном назначении даты. Дата контакта, предшествующая новому завершённому визиту, заменяется расчётом от нового визита. Будущие даты окрашивания не считаются завершёнными визитами.

Черновик содержит `schemaVersion`, `type`, `clientId`, `channel`, `recipient`, `dueDate`, `text`, `consent`, `idempotencyKey`, `status: draft`, `readyForProvider`. Последнее означает только наличие даты, контакта и согласия, а не подключённый канал, действительное разрешение API или отправленное сообщение. При `manual` черновик не создаётся. Сроки должны наступить до передачи сообщения адаптеру.

Следующий этап: серверное хранение клиентов и заданий, ежедневный worker, адаптеры официальных API Instagram/Telegram/WhatsApp/email, защищённые серверные ключи и webhooks результатов доставки. Конкретные разрешения, доступность исходящих сообщений и ограничения каждого API нужно проверить при подключении. Ник в соцсети не равен идентификатору получателя и сам по себе не даёт возможности писать через API.

Перед отправкой worker должен заново проверить срок, включённые напоминания, согласие, доступность получателя и сохранённый канал. Использовать `idempotencyKey` как уникальный ключ задания, чтобы повторный запуск не создавал повторное сообщение. Отключение или перенос напоминания должно отменять устаревшие задания. Хранить состояния draft/queued/sent/delivered/failed отдельно; отправка и доставка подтверждаются провайдером. Дневные лимиты и история контактов нужны до включения рассылки.

Сейчас расчёт обновляется при открытии/возврате во вкладку и раз в минуту в открытом приложении. Закрытый браузер не выполняет фоновые задачи. Доступны только ручной текст, копирование, переход в профиль, открытие почтового черновика и звонок; ни одно из этих действий не помечает сообщение отправленным.
